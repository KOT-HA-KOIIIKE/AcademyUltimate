Сервис проверяет корректность верстки статей через парсинг HTML. Сервис доступен по IP.
Как юзать:
1. Запускаем файл app.py;
2. Из терминала IDE переходим по ссылке на localhost (обычно http://127.0.0.1:80);
3. Видим простой веб-интерфейс.
4. Проверка опубликованных статей делается в левой половине экрана: вставить ссылку -> нажать "Проверить".
5. Проверка еще неопубликованных статей делается в правой половине экрана: открыть предпросмотр черновика -> ПКМ -> "Сохранить как" -> HTML -> "Сохранить" -> "Выберите файл" -> "Проверить".
